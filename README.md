# ritesh.github.io

Professional portfolio site for **Ritesh Goyal** — Principal DevSecOps Engineer.

## Live Site

Hosted on GitHub Pages at [ritesh.github.io](https://ritesh.github.io).

## Local Preview

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

- `index.html` — Single-page portfolio
- `styles.css` — Styles
- `main.js` — Navigation and scroll animations
